TSION MEKTIE | SQL & WEB DEVELOPMENT PORTFOLIO

FILES
- index.html: portfolio website
- style.css: styling
- salon_management.sql: MySQL/MariaDB practice database and queries

RUN THE SQL PROJECT
1. Start MySQL in WAMP or XAMPP.
2. Open phpMyAdmin.
3. Import salon_management.sql or paste it into the SQL tab and run.
4. Review the tables and test the JOIN, GROUP BY, and aggregate queries.

PREVIEW THE WEBSITE
Open index.html in a browser. To use a local server, place this folder in htdocs (XAMPP) or www (WAMP).
